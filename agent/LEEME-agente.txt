AGENTE VIGÍA PARA WINDOWS
=========================

1. Descomprimí esta carpeta donde quieras (por ejemplo C:\Vigia).
2. Abrí VigiaAgente.exe y entrá con tu usuario y clave (administrador o empleado).
   - Si esta PC tiene que ANALIZAR las cámaras (la PC central), dejá tildado «Esta PC analiza las
     cámaras» (solo administradores) y poné un nombre para la PC.
   - Si es un puesto de empleado para revisar alertas, destildalo.
   La sesión queda guardada (agente.env, al lado del .exe). "Cerrar sesión" para cambiar de usuario.
   Pestañas: En vivo (solo PC central), Clientes y cámaras, Alertas, Administración (solo admin).
3. Se abren dos ventanas: la negra (registro) y "Vigia - PC central": a la izquierda la lista
   de clientes y cámaras con su estado (elegí cuáles ver; un cliente = todas las suyas) y a la
   derecha el mosaico en vivo con las personas recuadradas. Podés cerrarla; el agente sigue.
   En el panel, Clientes -> cliente -> cámara, la cámara pasa a "En línea" en menos de un minuto.

Para que arranque solo con Windows: Programador de tareas -> Crear tarea básica ->
"Al iniciar sesión" -> Iniciar un programa -> VigiaAgente.exe, y marcar "Reiniciar si falla".

Opcional: instalar ffmpeg (winget install Gyan.FFmpeg) para que los clips pesen menos.
Si Windows Defender lo frena ("Windows protegió su PC"): Más información -> Ejecutar de todas
formas. Es un .exe sin firma digital; se compila desde el código del repositorio.
